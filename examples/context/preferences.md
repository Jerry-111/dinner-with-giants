# What Alex wants from the output

> **Fictional user for the bundled example.** Last updated 2026-11-14.

- Arguments, not reassurance. Show the strongest case against each option.
- About two-thirds on how each path actually works (who learns what, where value and risk come
  from, what is already too late), one-third on Alex's own choice.
- Conditional branches instead of one recommendation: "if X, then O2; if Y, then O3".
- For every path, the early signal that it is the wrong one.
- Keep disagreements visible; do not average them away.
- Plain, dense English. Technical terms are fine.
