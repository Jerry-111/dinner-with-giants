# Feedback log

> Chronological record of the user's feedback and decisions over time. Times in the run's own
> timezone; newest entry at the bottom. This file lives in `workspace/context/`, which is
> git-ignored except for its own README.
>
> Where this conflicts with `preferences.md`, this file wins — it's the more recent signal.
> Keep the same privacy limits as `user_profile.md`: no immigration/identity, finance, or
> health detail, even in a quoted aside.

  close to it> → <what changed as a result, or which run/file it produced>.
